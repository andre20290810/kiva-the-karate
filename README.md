# KIVA THE KARATE — セーパイ（2D・実写連続画像）

中央の人物（背景透過の実写連続画像 412 枚、0.2 秒間隔）の型を見ながら、動きに合うコマンド（Y 呼吸／X 構え／A 打撃／B 旋回）を
入力するリズムゲームです。成功すると人物に重なるエフェクトが出ます。譜面は編集モードで何度でも調整でき、JSON で保存できます。

旧版の 3D 表示（人体モデル・3D シーン・表示切替）は廃止しました。ページは `app/` だけを読み込み、公開用の `dist/` にも 3D の
コード・素材は入りません（`tools/build-dist.mjs` が検査）。

## 起動

```bat
npm install            :: playwright-core（ブラウザ確認用）だけ
npm start              :: http://localhost:8177/
npm test               :: 判定・長押し・AUTO・JSON 検証・配置の単体テスト
npm run test:browser   :: 実素材でのブラウザ確認（npm start を別に起動しておく）。ほかに test:audio・test:bgm・test:editor
```
`?fresh=1` を付けると、自動保存した編集内容を使わずに初期譜面で起動します。

## 画面

上から「背景付きのステージ」「操作パネル」。向きは表示領域の縦横比で決め（横長 = 横向きの背景、縦長 = 縦向きの背景）、
回転・リサイズしても再生位置・譜面の編集内容・AUTO は保たれます。

- **縦向き**: 背景は縦横比を保って全体を収め（余白は道場の色）、その矩形の中央に胴体の中心（両肩と両腰の中点）を置きます。
  直立時の全高は背景の高さの約 55%（`display.referenceHeightRatio`）。全コマがレーンの下〜背景内に収まらない画面では小さくします。
- **横向き**: 背景は表示領域を余白なく埋めます（cover。上下左右は切れてよい）。人物は背景とは別の前景で、左右の中央に置き、
  直立時の全高が表示領域の高さの 87%（`display.landscapeHeightRatio`）。実際に見える人物の高さは 412 コマで表示領域の 65〜97%
  （中央値 75%）。足元は全コマの下方向の広がり（99.5 パーセンタイル）が下端に収まる高さに固定し、頭や腕を上げたコマはレーンと重なります。
  表示順は奥から「背景 → レーンの背景・枠 → 人物 → ラベル・判定線・ノーツ」で、人物はレーンの面に隠れず、ノーツと判定線は人物の手前です。レーンと HUD はノッチの安全域の内側に置きます。
- **大きさの基準**: 倍率はコマ共通で、撮影距離による体格の変化だけを胴の長さ（前後のコマで強く平滑化）で補正します。
  しゃがみ・蹴りで外接矩形が変わっても拡縮せず、位置も跳ねません。離れた小さな塊（ゴミ・床の反射）は基準にしません。
- **4 レーン**: 背景の上部に上から Y・X・A・B。右から左へ流れ、左の判定線で押します。ノーツの位置は「判定時刻までの残り時間 ÷
  先読み時間（`settings.laneLeadSeconds`）」で決めるので、縦横でレーンの長さが違ってもタイミングは同じです。
- **漢字のノーツ**: ノーツは四角い枠ではなく文字そのもの（息＝Y、構＝X、撃＝A、旋＝B。`app/config.js` の `glyphs`）。
  黒い縁取りと影で背景から浮かせます。レーン見出しは「息／Y」など、画面のボタンも漢字を大きく、Y・X・A・B を小さく併記。
  流れる文字・長押しの終端・判定位置の火は、左端の判定の文字（見出し）と同じ大きさ・太さです（縦横とも同じ基準）。
  呼吸の長押しは始端と終端の両方が「息」で、間をレーンに平行な直線で結びます（線の長さ = 長押し時間）。
- **成功の火**（`app/glyphfire.js`）: 成功すると判定位置の文字そのものに赤い火が灯ります（文字の形から立ち上がる炎・赤熱・火の粉と余韻。
  文字は読めるまま）。呼吸は正しく保持している間に火が育ち、完了で強く灯ります。MISS・早すぎる解除では灯りません。
  火はノーツより先に描くので、次に流れてくるノーツを覆いません。AUTO も同じ演出です。
- **人物のエフェクト**（`app/fx.js`。番号は `app/effects-catalog.js` で固定）: ノーツごとに番号で選びます。

  | 番号 | 名称 | 内容 | 向き | 既定のコマンド |
  |---|---|---|---|---|
  | 0 | エフェクトなし | 人物には何も出さない（判定位置の文字の火は出る） | — | — |
  | 1 | 呼吸の気 | 人物の内側だけを巡る気の流れ・光の帯・粒子 | なし | 息（Y） |
  | 2 | 構えの発光 | 輪郭の光・体の上を走る光・胸元の閃光 | なし | 構（X） |
  | 3 | 打撃のエネルギー | 拳・足から攻撃方向へ伸びる光と火花・残像 | あり | 撃（A） |
  | 4 | 旋回の残像と風 | 直前のコマの残像・体を巻く空気 | あり（左右） | 旋（B） |

  番号 5（背後にまとう炎）は 2026-10-21 に廃止し、欠番です（再利用しない）。保存済みの設定や読み込んだ JSON に 5 があれば、
  息のノーツは 1、それ以外は 0 に置き換えます（時刻・コマンド・位置・強さなどほかの編集内容はそのまま。炎だけの高さ・幅は外す）。

  **呼吸の気（No.1）**: 人物の透過画像のアルファで切り抜き、人物が写っている所（頭・胴体・腕・脚）の内側だけで動かします。
  腕と胴体・脚の間などの透明な所や輪郭の外には、光・粒子・ぼかしも出しません（作業用画像に描いてから、画面と同じ画素の格子で
  人物のアルファを最後に掛ける）。気の流れが下から上へ巡り、光の帯が足元から頭へ上り、小さな光が体の中を上ります。
  色を重ねるだけで加算しないので、顔や道着の質感は白く潰れません。長押し中は進み具合で強まり、成功で体の中心から全身へ光が広がって収まります。
  人物の画像の切り替え・位置と倍率の補正・画面の回転には、表示している人物と同じ変換で追従します。一覧のプレビューも同じ描画です。
- **メモリ**: 切り出し済み WebP（合計 約 7 MB）を最初に全部取得し、デコード済み画像は再生位置の前後だけ（最大 48 枚）保持します。

## 操作

| 入力 | 意味 | 方式 |
|---|---|---|
| Y | 呼吸を整える | 長押し（開始の時刻・必要な時間の保持・早すぎる離しを判定） |
| X | 構える・構え直す | 単押し |
| A | 突き・蹴りなどの打撃（譜面の `action` で突き／蹴り／打ちを区別） | 単押し |
| B | 大きな向きの変更・旋回 | 単押し |

キーボード: Y X A B（押しっぱなしの自動リピートは無視）／ Space 開始・一時停止 ／ R リトライ。
画面のボタンはタッチとマウスの両方で使え、二重には数えません。ゲームパッド（標準配置）は **位置** で対応します:
上 = Y、左 = X、下 = A、右 = B（Nintendo 配置のコントローラーは印字と位置が違うので、画面のボタン名で確認してください）。
入力欄にフォーカスがある間、Y X A B はゲーム操作になりません。

判定の初期値: PERFECT ±60ms、GOOD ±120ms、許容限界 ±180ms（この外の入力は空振り）。設定パネルで変更でき、譜面 JSON に保存されます。
入力補正（`inputOffsetMs`）は ＋ にすると、押した時刻をその分だけ早い時刻として判定します（いつも LATE になる場合に ＋）。

**効果音はありません**（2026-10-21 に廃止）。息・構・撃・旋の音、成功・失敗の音、効果音の音量設定はなく、音を作る処理もありません。
古い保存設定に効果音の音量が残っていても読まずに消します。音は BGM（3 曲から選択）と元動画の音声だけで、それぞれ音量・ミュートを設定できます。

**AUTO**: 譜面のノーツを予定時刻ちょうどの入力として、通常プレイと同じ判定処理に渡します（Y は押して保持して離す）。
画面に「AUTO 再生中」と出て、結果は手動プレイの記録と区別されます（手動の最高記録には入りません）。
途中で切り替えても、過去のノーツをまとめて成立させたり、押したままの Y が残ったりしません。

## 編集モード（「編集」ボタン）

- 再生／一時停止、シーク（スライダー・タイムラインのクリック）、1 コマ送り（← →、0.2 秒）、速度 1×・0.5×・0.25×
- タイムライン: 4 レーン、ノーツをクリックで選択（Shift で追加）、空いている所をドラッグで範囲選択、ノーツをドラッグで移動、
  長押しノーツの終端をドラッグで長さ変更、Ctrl+ホイールで拡大縮小。「コマにスナップ」は任意
- ノーツの欄: 変わらない ID・時刻・コマ番号を表示。時刻（0.01 秒単位）、動作（A は突き／蹴り／打ち）、表示名、長押し時間、連続コマンド
  - **コマンド種別**（息・構・撃・旋）: 変えると文字・入力ボタンがそろって変わり、エフェクトはそのコマンドの既定に戻ります
    （前の打撃の方向や打撃点は残りません）。誤って「撃」になっている構えを「構」に直せます
  - **視覚エフェクト**: 番号・名称・プレビュー（そのノーツのコマに重ねた見え方）の一覧から選びます。コマンドを変えずに見た目だけ変えられます。
    「エフェクトなし」も選べます。「この動作で試す」で一時停止のままそのコマに重ねて再生、「前後を繰り返し再生」でノーツの前後を A–B ループ
  - **発生位置**（エフェクトの既定・胴体・頭・左右の拳・左右の足・画面で指定した位置）と、画面上の位置の調整（左右・上下）
  - **方向・角度**（打撃・旋回など向きを持つエフェクトだけ。構えの発光・呼吸の気などでは設定が出ません）。「画面で指定」「関節から自動」
  - **大きさ・強さ・持続時間**
- 追加（現在位置に ＋Y／＋X／＋A／＋B）、複製、削除（Delete）、選択したノーツをまとめて早く／遅くずらす
- 連続コマンド: 選択したノーツを新しいまとまりにする／外す、名前の変更、一覧の並べ替え、まとまり内のコマンドの順番の入れ替え
  （「◀ 順番」「順番 ▶」: 時刻の並びはそのままで、隣のノーツとコマンドの中身を入れ替える）
- A–B ループ（ゲームの A・B ボタンとは別の「ループ開始」「ループ終了」）、区間内のノーツを選択
- 人物の位置・倍率のコマ単位の補正（下の `frameOverrides`）、直立時の高さ、人物の中心。補正欄に入力を始めると再生が止まり、
  入力を始めたコマが対象として固定されます（コマ送り・再生で値も対象も変わらない）。「このコマに適用」か「取り消し」で終わります
- 元に戻す／やり直す（Ctrl+Z／Ctrl+Y）、JSON の書き出し・読み込み、編集メモ
- 保存（下の「設定の保存とデフォルト」）

### 設定の保存とデフォルト

| 操作 | 内容 |
|---|---|
| 自動保存（下書き） | 編集のたびにこのブラウザへ自動で保存。再読み込みしても編集が消えない |
| **この端末のデフォルトとして保存** | このブラウザだけの既定にする（下書きは消える）。保存後すぐ、通常プレイと AUTO の両方で使われ、再読み込み後も維持 |
| 編集前に戻す | 最後に「この端末のデフォルトとして保存」した状態（無ければ配布時の初期設定）へ戻す（元に戻すで取り消せる） |
| 配布時の初期設定に戻す | 公開版に入っている譜面（`charts/seipai_v2.json`）へ戻す（この端末のデフォルトは保存し直すまで残る） |
| この端末のデフォルトを消す | 次からは（下書きが無ければ）配布時の初期設定で起動 |

起動時は「下書き → この端末のデフォルト → 配布時の初期設定」の順に使います。編集欄に今どれを使っているかを表示します。
保存する内容はノーツ単位のコマンド種別・エフェクト番号・発生位置・位置の調整・向き・大きさ・強さ・持続時間で、
既存の譜面の内容と `frameOverrides` はそのまま保ちます。エフェクトの指定のない従来の JSON も読み込めます（コマンドの既定を使う）。

**この端末のデフォルトは、このブラウザにだけ保存されます。公開版は変わりません。** ほかの端末でも同じ設定で起動するには:

1. 編集モードで「JSON を書き出す」
2. `node tools/chart/adopt.mjs <書き出した JSON>`（検証して `charts/seipai_v2.json` に取り込む。`--dry-run` で確認だけ）
3. コミットして公開（DEPLOY.md）

シーク・ループ・リトライ・譜面の変更のたびに、その時刻以降のノーツの判定を初期化します（同じノーツを二重に加点しない、
前回の MISS が残らない）。シークより前の未判定のノーツは「対象外」として成績に数えません。

## 譜面 JSON（`charts/seipai_v2.json`、schemaVersion 1）

時間はすべて **連続画像の開始を 0 秒** とする同じ時間軸の秒数です。画像（base64 など）は含めません。

```jsonc
{
  "schemaVersion": 1,
  "gameVersion": "v2",   // 正式版（旧 ver2）。無い・"v1" の JSON は読み込まない
  "title": "セーパイ",
  "source": { "frameManifest": "assets/seipai_v2/manifest.json", "frameCount": 412, "frameIntervalSeconds": 0.2, "durationSeconds": 82.26839 },
  "audio": { "src": ["assets/seipai_v2/audio.m4a", "assets/seipai_v2/audio_opus.m4a"], "startAtTimelineSeconds": 0 },   // src は文字列か配列（先頭から順に試す）。null で音源なし
  "settings": {
    "inputOffsetMs": 0, "perfectWindowMs": 60, "goodWindowMs": 120, "missWindowMs": 180,
    "holdReleaseWindowMs": 150,   // 長押しの終了より この分 早く離しても成功
    "leadInSeconds": 2,           // 開始前の待ち時間
    "laneLeadSeconds": 2.4        // レーンの右端から判定線までの時間
  },
  "display": {
    "subjectAnchor": { "x": 0.5, "y": 0.5 },   // 胴体の中心を置く位置（背景の表示矩形内の 0〜1）
    "referenceHeightRatio": 0.55,               // 直立時の全高 ÷ 背景の高さ
    "frameOverrides": { "123": { "dx": 0.01, "dy": -0.02, "scale": 1.05 } }
  },
  "sequences": [ { "id": "opening", "label": "呼吸・構え・打撃" } ],
  "notes": [
    { "id": "n001", "time": 5.8, "button": "Y", "action": "breathe", "input": "hold", "duration": 2.6, "label": "呼吸", "sequenceId": "opening",
      "effect": { "preset": "breath", "intensity": 1 } },
    { "id": "n003", "time": 15.4, "button": "A", "action": "strike", "input": "tap", "label": "打撃", "sequenceId": "opening",
      "effect": { "preset": "strike", "anchor": { "x": 0.53, "y": 0.29 }, "direction": { "x": 0.1, "y": -1 }, "intensity": 1 } }
  ],
  "memo": [ "初期譜面の要調整箇所など" ]
}
```

| 項目 | 内容 |
|---|---|
| `button` / `action` / `input` | Y = `breathe`・`hold`（`duration` 必須）、X = `stance`・`tap`、A = `punch`／`kick`／`strike`・`tap`、B = `turn`・`tap` |
| `id` | ノーツごとに一意で変わらない ID（追加時は `n` + 連番） |
| `sequenceId` | 連続コマンドのまとまり（`sequences` の id）。各ノーツは個別に判定 |
| `effect.anchor` | 元の 720×1280 画像内を 0〜1 にした打撃点。中央配置・拡大縮小と同じ変換で画面に置く |
| `effect.direction` | 攻撃の向き（画面の右 = +x、下 = +y） |
| `effect.intensity` | 0〜2（PERFECT は 1 倍、GOOD は約 0.6 倍で表示） |
| `display.frameOverrides` | キー = コマ番号（0〜411）。`dx`・`dy` は背景の表示矩形の **高さ** に対する割合のずらし量、`scale` は自動倍率に掛ける倍率（0.2〜5） |

読み込み時は、形式・版・時刻の範囲・長押し時間・ID の重複・ボタンと action の対応・同じボタンの長押しとの重なり・
連続コマンドの参照・補正値を検証します。不正な JSON はメッセージを出して拒否し、今の編集内容は変わりません。
判定済みフラグやコンボなど、プレイ中だけの状態は保存しません。

## 初期譜面について

`charts/seipai_v2.json`（46 ノーツ）は、412 枚を 1 コマずつ確認し、動作が決まったコマに置きました
